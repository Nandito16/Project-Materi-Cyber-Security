Apa Itu SQL Injection?

Bayangkan

Database adalah tempat website menyimpan data pengguna (nama dan sandi) di sebuah lemari penyimpanan bernama database. Saat kamu masuk, website bertanya ke lemari penyimpanan:

"Apakah kamu menyimpan pengguna bernama X dengan sandi Y?"

Pertanyaan itu ditulis dalam bahasa khusus bernama SQL. Contohnya seperti ini:

Contoh Perintah SQL
SELECT * FROM pemain WHERE nama='budi' AND sandi='rahasia'

Kunci Ajaib

Masalah muncul jika website mengira input apa adanya dianggap perintah SQL. Penyerang bisa memasukkan teks yang mengubah logika perintah di dalam database.

Contoh ketikan pada kolom nama Efek
admin' OR '1'='1

Database memproses:

-

admin = nama pengguna

-

OR '1'='1' = perintah kondisi yang selalu bernilai benar

Pada website yang rentan, hal ini dapat membuat pemeriksaan login gagal yang tidak seharusnya.

SIMULATION

Pastikan Kamu sudah membuka website "TopUpDOOR" ya!

Buka halaman login admin (/admin) seperti simulasi "Directory Scanning"

Pada kolom Username, masukkan kunci ajaib:

admin' OR '1'='1 dan kolom Password apa saja.

Hola!! Kamu berhasil masuk ke halaman admin tanpa perlu memasukkan sandi yang benar. Ini adalah salah satu contoh nyata dari SQL Injection!

Cara Melindungi Pintu Login

Cara Penjelasan
Pisahkan Perintah dan Masukan Website harus membedakan teks yang diketik pengguna dengan perintah untuk database. Jadi, ketikan seperti kata ajaib tidak bisa sembarangan mengubah perintah SQL.
Periksa Masukan Pastikan data yang dimasukkan sesuai kebutuhan. Contohnya, kolom umur hanya menerima angka.
Batasi Hak Akses Berikan izin database seperlunya saja agar tidak semua data bisa diubah atau dibuka sembarangan.
Lindungi Kata Sandi Jangan menyimpan kata sandi dalam bentuk asli. Gunakan metode pengamanan khusus agar kata sandi tidak mudah diketahui jika data bocor.
Sembunyikan Pesan Error Jangan tampilkan detail kesalahan database kepada pengunjung karena bisa membocorkan informasi penting website.
