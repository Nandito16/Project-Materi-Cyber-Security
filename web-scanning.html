⚠️ Memindai website milik orang lain tanpa izin itu DILARANG

  1. Selalu minta izin dulu. Memindai website orang lain tanpa izin bisa melanggar hukum, sama seperti mengecek-ngecek pintu rumah tetangga satu per satu.
  2. Hanya pindai milikmu sendiri atau website latihan khusus yang memang dibuat untuk belajar.
  3. Kalau menemukan lubang keamanan, laporkan. Beri tahu orang dewasa atau pemilik website. Jangan diutak-atik, jangan disebar.
  4. Ilmu ini untuk melindungi, bukan merusak. Detektif yang baik menjaga, bukan mencuri.

Apa Itu Web Scanning?

Bayangkan

Sebelum tidur, kamu berkeliling rumah: "Pintu depan terkunci? Jendela dapur tertutup? Ada pintu belakang yang lupa dikunci?"

Web Scanning persis seperti itu, tapi untuk website. Kita memeriksa: website ini dibuat pakai apa? dan halaman apa saja yang ada di dalamnya?

Alat

Detektif website biasanya menanyakan:

Alat Pertanyaan
WhatWeb "Kamu terbuat dari apa?"
Server, bahasa program, versi
Alat ini tidak merusak apa pun mereka hanya melihat dan mencatat.

Cara Kerja

Setiap website diam-diam "memperkenalkan diri" saat kita membukanya. Website mengirim catatan kecil berisi nama server dan versinya.

WhatWeb — “Kamu Terbuat dari Apa?”

🧠 Cara Kerjanya

Setiap website diam-diam “memperkenalkan diri” saat kita membukanya. Ia mengirim catatan kecil berisi nama server dan versinya. WhatWeb membaca catatan itu lalu merangkumnya.

Seperti melihat label di kaus: “bahan katun, ukuran M, buatan 2019”.

Kenapa penting? Kalau sebuah website memakai versi program yang sudah tua, biasanya versi itu punya kelemahan yang sudah diketahui umum. Pemilik website perlu tahu ini supaya bisa memperbaruinya.

    Gobuster — “Pintumu Ada di Mana Saja?”

    🧠 Cara Kerjanya

    Gobuster punya daftar kata (disebut wordlist) berisi nama-nama folder yang umum: /admin, /backup, /uploads, dan ribuan lainnya.

    Ia mencoba satu per satu: “Ada halaman /admin tidak?” Kalau website menjawab ada, Gobuster mencatatnya.

    Mirip tukang pos yang mengetuk tiap pintu untuk tahu pintu mana yang berpenghuni — ia tidak masuk, hanya mencatat.

    Arti kode angka:
    200 = halaman ada dan terbuka
    301 = ada, tapi dialihkan ke tempat lain
    403 = ada, tapi dilarang masuk
    404 = tidak ada apa-apa

      Cara Melindungi Website

      Masalah Cara Memperbaiki
      Versi server terlihat
      nginx/1.18.0       		Sembunyikan nomor versi di pengaturan server, supaya penjahat tidak tahu kelemahan mana yang bisa dicari.
      Program sudah usang
      PHP/WordPress lama       		Rajin perbarui (update) semua program ke versi terbaru. Ini pertahanan nomor satu.
      Folder bisa diintip
      /uploads terbuka       		Matikan directory listing supaya isi folder tidak bisa dilihat sembarang orang.
      File rahasia terbuka
      /backup, /.git       		Jangan pernah menaruh file cadangan atau kode sumber di dalam folder website yang bisa diakses publik.
      Ditebak terus-menerus
      Ribuan percobaan       		Pasang pembatas kecepatan (rate limiting) supaya satu orang tidak bisa mencoba ribuan alamat dalam sekejap.
